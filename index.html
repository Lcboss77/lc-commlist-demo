lc-commlist: in-game commands and keybinds list

Players type /commands and see every command and keybind your server offers, read live from your database. Admins add entries from chat. Everything below runs in your browser: use the stage to try each function.

Install

  1. Import commands.sql (creates the commands and keybinds tables).
  2. Make sure es_extended and oxmysql are running.
  3. Add ensure lc-commlist to your server.cfg.
  4. Give your admin the ESX admin group, then use /addcommand and /addkeybind in-game.
/commands                                    open the list (any player)
/addcommand <command> <description...>        add a command (admin)
/addkeybind <key> <description...>          add a keybind (admin)
This page is a browser simulation of the server side. The interface you see on the stage is the script's own index.html, style.css and index.js, unchanged.
